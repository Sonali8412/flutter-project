# Flutter Learning App

A simple Flutter application created for learning Flutter development concepts such as navigation, multiple screens, widgets, and UI design.

## Features

- Profile Page
- About Page
- Contact Page
- Company Page
- Navigation between multiple screens
- Clean and simple user interface
- Cross-platform Flutter application

## Getting Started

### Prerequisites

- Flutter SDK
- Android Studio / VS Code
- Android Emulator or Physical Device

### Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/flutter-learning-app.git
```

2. Navigate to the project folder

```bash
cd flutter-learning-app
```

3. Install dependencies

```bash
flutter pub get
```

4. Run the application

```bash
flutter run
```
